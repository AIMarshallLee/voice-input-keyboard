# VoType 体验候选版门槛

本文件定义“可以发给真机验收”的最低条件。CI 编译成功不等于体验完成；任一
阻断项失败时，不生成新的 TestFlight 候选版。

## 语音主链路

| 场景 | 自动验收标准 | 真机最终验收 |
| --- | --- | --- |
| 已开启免切换待命 | 键盘读取到新鲜 `standby`，直接发送会话请求，不调用冷启动 | 点实心麦克风不切 App，1.5 秒内进入聆听 |
| 待命失效或被系统关闭 | readiness 3.5 秒自动过期，键盘改为空心麦克风 | 不显示假待命；点击能短暂打开 VoType |
| 热路径无响应 | 1.2 秒自动降级冷启动，3 秒显示明确人工恢复动作 | 不允许无限停留在“打开后即可说话” |
| 录音中 | 同 session 实时文字、停止与终态隔离 | 切 App/切输入框不串结果，点一次停止 |
| 中断/权限/音频路由异常 | 原会话产生明确错误或安全降级，不迟到回填 | 电话、Siri、蓝牙切换后可重新开始 |

## 普通键盘与中文拼音

- 中文模式必须是默认普通输入模式，支持连续拼音、候选点选、空格首选、
  中英/数字/符号切换和长按删除。
- 完整词条优先于逐字拼接；固定语料的 Top-1、Top-5 结果写入测试，不靠主观描述。
- 用户明确选择过的候选必须在同拼音下本地提升，并在扩展重建后保留；学习
  仅能调整词库已有候选，设 2,000 个拼音、每拼音 16 个候选的容量上限。
- 候选生成性能目标：热查询 p95 小于 40 ms，单次最坏值小于 100 ms；键盘
  扩展峰值内存目标小于 45 MB。性能数据必须由 macOS/iOS CI 或真机记录。

## 自动化门禁

发 TestFlight 候选版之前必须全部满足：

1. XcodeGen 工程生成成功，iOS Simulator 全量 XCTest 通过。
2. Release `iphoneos` 主 App 与键盘扩展均编译成功。
3. readiness 过期、热转冷降级、取消、会话替代、迟到终态均有回归测试。
4. 拼音固定语料、候选学习持久化、去重和性能基准通过。
5. 模拟器宿主 UI 能开启/关闭待命状态并显示失败态；键盘 UI 状态机不出现无响应态。
6. 连续运行语音/拼音回归至少 20 轮，无崩溃、串会话或不可恢复状态。

## 产品声明边界

在完整基准与真机矩阵通过前，只描述已验证能力，不宣称“全面超过 Typeless”或
“全面超过微信输入法”。目标是先在核心语音闭环、原地反馈与失败恢复上做到更
快、更透明；中文词库、长期语言模型和系统级兼容性需要持续用固定语料量化。
